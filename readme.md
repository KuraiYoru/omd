## Стилистика кода

В проекте соблюдаются стандарты **PEP 8** со следующим исключением:
* **Максимальная длина строки:** `120` символов.

Для проверки соответствия кода стандарту **PEP 8** используется линтер flake8.

Никаких сторонних зависимостей не используется.

Для запуска кода достаточно выполнить команду `python omd.py`.
